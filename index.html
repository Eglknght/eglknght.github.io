Proyek

Proyek Unggulan

Inventory Management System

Node.js · Express · MySQL · EJS

Aplikasi manajemen inventaris berbasis web dengan sistem autentikasi, kontrol akses bertingkat, dan visualisasi data, dibangun dengan arsitektur MVC untuk memisahkan logic, data, dan tampilan secara jelas.

Autentikasi Session-based auth kustom (express-session), password ter-hash dengan bcryptjs, dilengkapi middleware pencegah akses halaman terproteksi lewat tombol back setelah logout.
Kontrol akses Role-based access — hak akses admin dan staff dibedakan sesuai kewenangan masing-masing, diterapkan di level route/middleware.
Dashboard Ringkasan data real-time (total produk, kategori, stok menipis) dan doughnut chart distribusi stok per kategori menggunakan Chart.js.
Transaksi stok Form stok masuk/keluar dengan pencarian produk client-side (autocomplete tanpa reload) yang mendukung pemilihan beberapa produk sekaligus, lengkap dengan validasi kecukupan stok.
Laporan Riwayat stok yang bisa difilter per produk (termasuk tampilan "Semua Produk") dan rentang tanggal, dengan export ke CSV/Excel/PDF/Print.
Manajemen data CRUD penuh untuk produk dan kategori, tersimpan di database relasional MySQL.
Express.js MySQL (mysql2) bcryptjs express-session Chart.js EJS
